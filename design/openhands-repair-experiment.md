# OpenHands 修复引擎分支试验

2026-10-20，分支 `experiment/openhands-repair`。用户授权：接入、5 题小样本、遇错修复复测，通过后按每批 10 题顺序执行 100 题。

## 模块边界

保留四阶段平台及人工确认、原始证据、隔离副本、独立验证和人工接受。OpenHands 只替换修复阶段的候选生成与内部读改测循环，不替换漏洞发现、复审和规则生成。

- API `RepairRequest.engine` 显式选择 `native` / `openhands`；默认保持 `native`，便于对照和回退。
- `workflows/repair_openhands.py` 保持薄图入口；平台准备目标语义、调用引擎、重新应用候选、独立验证、持久化最终状态。
- `services/repair_openhands.py` 负责确认目标、冻结交接契约及产物引用。引擎解释不能扩大授权范围。
- `adapters/repair/openhands.py` 管理 SDK 外部进程、任务容器和停滞保护；模型凭据仅传入控制进程，不传给命令容器。
- `adapters/repair/agent_workspace.py` 负责源副本、文档别名保留、候选边界和最小精确替换导出。
- SDK 运行目录 `system/agents/openhands`，独立环境和 `uv.lock`，固定 `openhands-sdk==1.56.0`，不修改主应用依赖环境。
- 提示独立版本 `repair-openhands.v1.txt` / `v2`；SDK 版本、模型配置、事件、工具、候选及独立验证均留存。

## 执行契约

任务容器只挂载本任务候选目录、可选的项目依赖环境和独立开发套件。后两者只读。容器断网、根文件系统只读、无额外能力、不挂载 Docker socket 或平台工作区。

SDK 在空临时控制工作区运行，其工具通过固定容器 ID 执行命令。每次命令有时间和输出限制。SDK 禁用自动供应商重试，单请求 90 秒，最多 100 步；引擎无实际事件/日志进展 240 秒或总墙钟 1800 秒终止，保留记录。

候选退出后以整个副本差分核查。测试、锁文件或未授权文件发生变更，整份候选拒绝；Python AST 未改变的纯注释/格式修改不能算运行时修复。输出为最小、唯一、能在原快照重放的替换窗口，再由平台重新应用及验证。SDK 自报完成不等于验证成功。

仅规范化快照内、目标仍在快照内的 Markdown 文档别名，不跟随任意链接；外部、代码或目录链接拒绝。原始研究输入不修改，保留规范化清单及衍生快照身份。

## 实验与批处理

抽样种子 `464304948`，从此前 15 项本地校准任务中一次无替换随机抽取：

1. CVE-2023-6681
2. CVE-2018-7753
3. CVE-2025-62800
4. CVE-2023-30608
5. CVE-2025-43859

不因曾失败、符号链接或难度更换样本。它们已参与开发或查看过隐藏失败，属于开发回归，不是新的独立泛化验证。默认模型沿用当前 DeepSeek 配置，不冒称复现论文 Claude/OpenHands 组合。

准入：5 项都有终态，基础设施未决为 0，至少 2 项同时通过正式功能和安全评分；所有导出仍遵守范围与原快照保护。准入在执行前冻结，未达到时停止，不自动降低阈值。

固定流水线：小样本 → 准入 → 冻结同版实现供全量使用 → 10 个顺序批次，每批 10 项。每题分别保存 input、模型开始标记、generation、result；每批保存结果引用。已有合法结果不重复收费执行。异常暂停待日志复核，修复版本使用新目录，失败历史不覆盖。

全部 100 项均进入执行计划。历史仅 15 项本地 oracle 校准有效，另外 85 项不因引擎变化自动变得可评分；生成产物与最终评分必须分列，环境、不可评分和失败不得计成功。若后续改 oracle，需另建明确版本，不能静默改变本轮分母。

成本以真实 token/请求收据为依据。DeepSeek 别名未收录 SDK 价格表时，SDK 的 0 成本估计不代表免费，报告费用为未知。保留原生准备/复核与 OpenHands 内部请求的分别用量，不把供应商中断当作补丁失败。
