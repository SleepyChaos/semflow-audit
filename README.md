# AI Code Audit

结合 CodeQL 静态分析、AI 主动取证、修复验证和 RAG 规则生成的代码审计平台。

## 当前状态

设计与仓库初始化阶段。尚未实现应用或安装依赖。

## 审计流水线

1. **CodeQL 审计**：上传代码包，固定源码快照，建库和扫描，保存原始告警及证据。
2. **AI 复审与补充发现**：复核静态告警，按目标主动获取上下文，提出候选并保存确认状态。
3. **修复 Diff 与报告**：针对已确认缺陷生成补丁，执行验证，输出 Diff 和报告。
4. **RAG 生成规则**：从明确需求或已确认缺陷生成规则/模型，验收通过后发布。

流程由 LangGraph 主图与子图表达。CodeQL 建库、扫描、规则编译和验证通过独立适配器调用。
