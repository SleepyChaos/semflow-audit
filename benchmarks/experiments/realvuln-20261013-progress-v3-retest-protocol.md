# RealVuln 四项目增量补测

2026-10-13。先完成 `20261013-progress-v2` 全 26 项目实验，同时另行补测 OWASP Web Playground、PyGoat、Python App、Python Insecure App。后三者因用户确认的临时断网出现模型超时或连接失败；OWASP 复核因连续证据门拒绝触发 no_progress，后续候选未处理。

本次实现冻结在 `artifacts/research/realvuln/20261013-progress-v3-retest/implementation`。与 v2 冻结 app 唯一差异为 `adapters/ai/policy.py`：结构化候选判断被证据门拒绝时，不再将该 partial 批次算作无进展，允许继续调查其他候选；连续协议/执行失败及没有有效产物的空批次仍保留保护。单批次取证步数、恢复次数、源码证据门保持不变。

四项目均创建新的 audit_id、初审和复核执行，模型、提示版本与 v2 保持一致。源码与标注不变，逐文件实现散列、源码散列单独核验。复用 v2 已成功的 CodeQL 数据库与 SARIF，并核验 CLI、查询包、套件、快照；明确 `static_not_rerun=true`，不把它算作第二次实际扫描成本。

补测项目并发 1。v2 实验继续独立运行，原失败记录不覆盖、不删除。v2 完整 26 项目分数与四项目补测分数分别报告。若提供结合补测的全量汇总，必须标明它由 v2 的 22 个项目和 v3 补测的 4 个项目组成，不可描述为全 26 项目统一新实现重跑，也不可按标签择优选取单条候选。

任何模型失败仍明确保留，未决不得默认为排除。不得将没有完成全 26 项目的补测目录作为统一全量正式实验报告。
